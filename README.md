# Quiz Oghams

Mini-site autonome basé sur les 25 fiches finales exportées depuis Notion.

## Ouvrir localement
Double-cliquer sur `index.html`.

## Publier gratuitement
Le dossier peut être déposé tel quel sur un hébergement statique (GitHub Pages, Netlify, Cloudflare Pages, etc.).
Aucune base de données ni dépendance n'est nécessaire.

Les scores et erreurs sont conservés localement dans le navigateur.
